# Placement Cell Career Analytics Portal - Frontend

A lightweight, modern web frontend implemented purely with **HTML5**, **CSS3**, and **JavaScript** (Vanilla JS).

## Features
- **Zero Node.js/NPM Build Dependencies**: No Vite, Webpack, or Babel needed. Open directly or serve via Flask.
- **Dynamic Views**:
  - Dashboard with summary metric cards and recent placement offers.
  - Student Management with full CRUD, skill tagging, and eligibility toggling.
  - Placement Records with offer tracking and duplicate placement management.
  - Department Analytics comparing discipline and sub-branch performance.
  - Package Analytics with NumPy central tendency statistics and salary tiers.
  - Skill Insights analyzing placed vs. unplaced student technical skill distributions.
  - Settings for term management and database status.
- **Matplotlib Chart Export**: One-click download of server-generated analytical charts.
- **Interactive Visualizations**: Powered by Chart.js loaded via CDN.
